1 · the parts

Skills tell, hooks enforce, agents do, reports connect them.

A skill is text the model can ignore; a hook is a program it cannot argue with.

Skill

the manual

A short rule sheet the model reads before a kind of work: Python style, reviewing, reporting.

Advice: the model can skip it.

Hook

the turnstile

A small program Claude Code runs before or after an action. It can refuse the call, add a note or hold the turn.

Enforced: the model cannot argue.

Agent

a contractor

A separate session with one role, its own tools, preloaded skills and a turn budget. It does one job and hands back.

Works in parallel, from a brief.

Report

a signed timesheet

The fixed form every agent ends with. A skill says how to write it; a hook checks it against what the agent did.

Where advice meets enforcement.

The top four levels are enforced by a hook. A reminder never stops anything; advice is up to the model.

Stopped

The command never runs. The agent is told which rule fired and what to do instead.

  • Deleting files is refused. With a scratch folder set, rm of named files inside it is allowed.

    e.g. rm -rf build/, git clean -fdguard.pyClaudeCortexKiro

  • Rewriting shared history is refused.

    e.g. git push --force, git reset --hardguard.pyClaudeCortexKiro

  • A wildcard the shell would get wrong is refused: one that matches no file, or one meant for the command itself.

    e.g. ls *.nothing; write find . -name '*.py', quotedguard.pyClaudeCortexKiro

  • An agent without a harness role is refused.

    e.g. a general-purpose agent; send the brief to harness:scout or harness:workerbrief_lint.pyClaudeCortexKiro

  • An agent past its turn budget can only hand back its report.

    e.g. a worker past its 70 turnsbudget.pyClaudeCortexKiro

  • A commit message must look like fix(hooks): keep the last token followed by bullet lines, and must never credit an AI.

    e.g. git commit -m "fixed stuff", or a Co-Authored-By line naming an AIcommit_gate.pyClaudeCortexKiro

  • A project can name a wrapper that every Python run must go through, such as a queue that shares one GPU; a bare run is then refused.

    e.g. python train.py without the wrapperguard.pyClaudeCortexKiro

Asks you

Claude Code pauses and asks you. Your yes runs it.

  • Adding or removing packages asks you first.

    e.g. pip install requests, uv add httpxguard.pyClaudeCortexKiro

Sent back to redo

The report goes back to the agent, naming only the parts that are wrong, up to 3 times. It is checked when the agent hands it back, so the agent can still fix it.

  • A report needs its parts: what was done, what is not proven, and a verdict of done, partial or blocked.

    e.g. a report with no ## Verdictreport_gate.pyClaudeCortexKiro

  • Each claim must match what the agent really did.

    e.g. "tests pass" with no command run, or a changed file it does not namereport_gate.pyClaudeCortexKiro

  • A report stays short: at most 6000 characters outside code blocks.

    e.g. a whole test log pasted as prosereport_gate.pyClaudeCortexKiro

Turn can't end

Your turn does not end until the main session fixes this; it gets 3 tries.

  • A long turn ends with a closing status, and waits while background agents still run.

    e.g. after 3 or more edits or agent calls: Verdict, Done, Needs you, Next, Lessonsturn.pyClaudeCortexKiro

  • A turn that ran agents names each one under ## Agents, with its verdict.

    e.g. - find the config loader: done, no problemsturn.pyClaudeCortexKiro

  • A lesson must change a rule file, or the status says Lessons: none.

    e.g. "Lessons: be more careful" with no rule changedturn.pyClaudeCortexKiro

  • A retro is due when 20 feedback items wait.

    e.g. the analyst groups them and proposes up to three rule changesturn.pyClaudeCortexKiro

Gets a reminder

The call runs. The agent gets one line of advice with the result.

  • The rules for a kind of file arrive before its first edit.

    e.g. the first edit of a .py file brings the Python style rulesskill_gate.pyClaudeCortexKiro

  • A brief missing a line its role needs gets a note.

    e.g. a worker's brief needs Goal:, Write set:, Judge:brief_lint.pyClaudeCortexKiro

  • Wasted reads and hidden failures get a note.

    e.g. the same small file read twice; pytest | tail without pipefailnudge.pyClaudeCortexKiro

  • A sleep that would block the session is removed or moved to the background.

    e.g. sleep 30 && make testguard.pyClaudeCortexKiro

  • Edit and Write change project files as usual. Shell commands that write files (echo > file, tee, cp, sed -i) should land in the scratch folder inside the project; elsewhere they still run, with a note. A shell write under /tmp also runs, with a note.

    e.g. echo hi > notes.txtguard.pyClaudeCortexKiro

  • A repo can set delegate so the main session gets a note whenever it edits files itself instead of handing the work to agents.

    e.g. the main session runs sed -i on a source filedelegate.pyClaudeCortexKiro

Advice only

Text the model reads before a kind of work. Nothing checks it was followed; a reviewer or a retro catches what slips.

  • Code style, one skill per language.

    e.g. code-python, code-js, code-shellskills

  • Cheap tool calls: one script per job, the checks chained in one call.

    e.g. tool-habits, put in front of every session and agentcontext.pyClaudeCortexKiro

  • How to brief, review, audit, test, debug and refactor.

    e.g. review, testing, debugskills

  • When to hire agents at all: the main session works directly by default.

    e.g. orchestrator, workflowsskills

5 · gaps

What the harness does not cover yet

Ranked by how likely each is to let a real mistake through.

high

Passing cases are not a live session

They pass 943 cases and 442 planted bugs, but no real session under claude --plugin-dir . has used them yet.

Next: one live session in a fresh repo.

high

Kiro and Cortex never run for real

The port is tested with a stand-in; Kiro's sub-agent field name is a guess.

Next: one install on each tool.

high

Workers can edit outside their write set

The report gate checks that each changed file is named, not that the brief allowed it.

Next: a note when a change falls outside Write set:.

medium

Budgets count turns only

No tokens or time per agent run reach the ledger.

Next: record them in the report gate.

low

The guard reads command text

A Python script that deletes files, or a command built from variables, gets through.

Accepted: it is not a sandbox.

low

Read-only agents still have Bash

A shell command can write a file; only the guard applies.

Accepted: probes need Bash.
