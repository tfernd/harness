Harness

A plugin for any coding agent (Claude Code, Cortex Code, Kiro): agents do the work, skills tell them how, and hooks enforce the rules.

  • 11 agents
  • 28 skills
  • 10 hook scripts
Install
claude plugin marketplace add tfernd/harness && claude plugin install harness@harness --scope user

Then restart Claude Code or run /reload-plugins, and /harness:init once per project.

curl -fsSL https://raw.githubusercontent.com/tfernd/harness/main/install.sh | sh -s -- cortex

Run it again to update; add --uninstall after the tool name to remove it.

curl -fsSL https://raw.githubusercontent.com/tfernd/harness/main/install.sh | sh -s -- kiro

Run it again to update; add --uninstall after the tool name to remove it.

How hard each part binds

A level is how firmly a rule holds, from a hard stop at the top to written advice at the bottom.

Hooks enforce the top four levels. A reminder never stops a call; advice is up to the model.

Hook notes

Model decidesnothing checks

Point at a level to light its parts on the right; click to keep it lit.

Stops the call. The call never runs; the agent is told which rule fired and what to do instead. Lights 5 hooks: guard.py, brief_lint.py, budget.py, commit_gate.py, delegate.py.

Asks you. Claude Code pauses and asks you; your yes runs it. Lights 1 hook: guard.py.

Sent back. The report goes back to its agent, naming only the parts that are wrong, up to 3 times. Lights 1 hook: report_gate.py.

Turn can't end. The main session's turn does not end until it adds what is missing; it gets 3 tries. Lights 1 hook: turn.py.

Reminds the model. The call runs; one line of advice comes back with the result. Lights 6 hooks: skill_gate.py, brief_lint.py, nudge.py, budget.py, guard.py, delegate.py.

Advice. Text the model reads before a kind of work. Nothing checks it was followed; a reviewer or a retro catches what slips. Lights all 28 skills and context.py.

Written down. Your project's own rules in AGENTS.md, written once by /harness:init; they bind as far as the model reads them. Lights nothing on the right: AGENTS.md is your project's own file.

Checkers

Test someone else's work, claim by claim.

  • agentreviewer

    Reviews one unit of code and its tests, a design, a branch or a pull request against its spec by the review skill - severities A to C, each finding with the input that shows it.

    Model
    sonnet
    Tools
    read-only, 35 turns
    Preloads
    report, review, evidence
    Use
    Use once at the end of a round, on the whole diff, after the product has run; the brief names the lens if one applies.

  • agentauditor

    Tests another agent's report - re-runs its judges, marks each claim true or false with evidence, checks the write set and grades the author's work.

    Model
    sonnet
    Tools

    Preloads
    report, audit, evidence
    Use
    Use when a worker's report is the sole evidence of a claim.
