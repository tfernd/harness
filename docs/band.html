The agent band

A mod that sits above the Claude Code prompt and shows the session and its agents.

← Back to the Harness Map

claude plugin marketplace add tfernd/harness; claude plugin marketplace update harness && claude plugin install harness-band@harness --scope user && claude plugin update harness-band@harness

Run it again to update. Then restart Claude Code or run /reload-plugins.

claude plugin uninstall harness-band@harness

Restart Claude Code or run /reload-plugins. The harness plugin is not touched.

What you see

  • Status. Working or idle, and how long the turn has run.
  • Rings. How full the context window is, and the 5 hour and weekly limits.
  • Cache. How long until the prompt cache goes cold.
  • Counts. Agents live, done and failed.
  • Timeline. One row for the main session and one per agent, grouped by workflow. Blue is thinking, green is a tool call.

Try it

The band is its own plugin, installed apart from the harness and working with or without it. It runs in Claude Code only. For the harness itself, see the Harness Map. Install it from the box at the top.
