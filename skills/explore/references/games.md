# Exploring a game

Add these to the loop in `harness:explore`.

- **Find the fun before the engine.** Ask what the player does each second and why it is worth repeating.
- **One prototype per mechanic.** Scope is the difference between a prototype and a feature
  (https://create.roblox.com/docs/production/game-design/prototyping.md).
- **Greybox and placeholder art.** Function over form; polish comes later
  (https://www.wayline.io/blog/myth-polish-truth-prototypes-fun).
- **Playable in the first round** when the question is how it feels. A static picture cannot answer that.
- **Playtest loop:** observe, change one thing, test again.
- **Set the architecture first:** logic apart from the view, before an AI adds features, so you keep creative control
  (https://spin.atomicobject.com/creative-control-game-developer/).
